## Purpose

NCPortfolio is a mobile portfolio application that presents my profile, skills, education, projects and personal information in a simple Android application.

The app is designed so that a recruiter, lecturer or reviewer can quickly understand my profile and view my work.

## Main Features

- Home screen with personal identity and biography
- Verification code displayed in the application
- Skills section
- Education and training information
- Projects section
- Separate Project Detail screens
- Bottom-tab navigation
- Nested project navigation
- Editable profile information
- Field-level form validation
- Valid profile data can be saved
- AsyncStorage persistence
- Saved profile remains after closing and reopening the app
- Gallery and camera image selection
- Image preview
- Replace and remove selected image
- Verification-card image preview
- About screen with application and student information
- Core application functionality works offline
- Standalone Android APK

## Technology Stack
