# Build and submission guide

## 1. Before coding
1. Install Node.js LTS.
2. Extract the project ZIP.
3. Open the `MOB_A2_2527201` folder in VS Code.
4. Open Terminal → New Terminal.
5. Run `npm install`.
6. Run `npm run typecheck` and resolve any reported issues.
7. Run `npx expo start`.

## 2. Check your identity
- Home must begin with: `My name is NDATIMANA Christine.`
- About screen verification code: `MOB-A2-7201`
- The same identity sentence is in the README.
- The same sentence and identity must appear on page 1 of the final UI/UX PDF.

## 3. Personalize portfolio content
- Replace the five skill placeholders with skills you can honestly demonstrate.
- Replace both project placeholders with genuine work and explain your actual contribution.
- Add your own profile photo or student-created avatar.
- Do not invent education dates, achievements or project outcomes.

## 4. Run tests
Use the test log template in `evidence/`. Only record actual results after testing.

## 5. Build the standalone APK
Use the commands in README.md. EAS Build requires an account and internet connection. The APK is not included in this source ZIP because it must be built and tested.

## 6. GitHub
Create a personal repository named `MOB_A2_2527201`. Commit meaningful changes, push the repository, then create a release tagged `v1.0.0`. Record the real commit hash and release/download links.

## 7. Final ZIP
The assignment requires one ZIP on the INES e-learning platform. Include the completed source, UI/UX PDF, test log PDF, declaration PDF, AI-use disclosure, actual APK and demo video. Do not include `node_modules`, `.expo`, caches, secrets or unrelated files.
